## Memorizing

For wire sequences, I split up each table into chunks to make it easier to memorize.

### Red

- **C, B, A**: Pretty straightforward.
- **AC, B, AC**: A sandwich, the reverse of the first part of blue.
- **ABC, AB, B**: I remember that the last row is **B** and we need to get there from the 6th
  row only changing one letter at a time. So from **AC** we add **B**, then remove **C**, and
  finally remove **A**.

### Blue

- **B, AC, B**: A sandwich, you can remember that the outsides are **B** and the inside is
  everything except **B**.
- **A, B, BC, C**: I remember **ABC** except you have **BC** between **B** and **C**.
- **AC, A**: I remember that the last row is **A** and we need to get there from the 7th row
  only changing one letter at a time. So from **C** we add **A**, then remove **C**.

### Black

- **ABC**: First one is anything.
- **AC, B, AC, B**: Remember that it's **AC, B** twice.
- **BC, AB, C, C**: I remember that there were two options for Calc, **BC** and **AB**, and you
  get a **C** in both of them.

### Observations

- The 5th row across all colors is only **B**.
- Blue and Black share rows 2 and 3 while Red and Black share rows 4 and 5.
- The last row for each color is different: **B, A, C**

## In-game Memory

In game, I keep track of the number of occurrences of each color by saying three numbers after
each panel. I like to say them in the order that I memorized the colors: Red, Blue, Black. So if
you see Blue, Red, Blue in the first panel and click next, say 1, 2, 0 while the next panel is
loading.
